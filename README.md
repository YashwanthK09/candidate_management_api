# Candidate Management API

A simple REST API for managing internship candidates, built using Python, FastAPI, SQLAlchemy, and SQLite.

## Features

- Candidate registration
- Candidate listing
- Candidate details
- Candidate update
- Candidate deletion
- Role selection
- Application status management
- Input validation
- Error handling
- Search and filtering

## Tech Stack

- Python
- FastAPI
- SQLAlchemy
- SQLite
- Pydantic
- Swagger/OpenAPI
- Postman
